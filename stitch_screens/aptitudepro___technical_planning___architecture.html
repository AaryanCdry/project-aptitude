# Meeting 3 Summary — Architecture & Technical Planning ## Key Decisions Made * **User Role Hierarchy:** Super Admin → College Admin → Sub-Admin (HOD level) → Mentor → Student. * **Data Isolation:** Multi-tenant architecture where each college has an isolated data "box". * **Build Order Flip:** Admin-first development. "Impress the college admin first." ## Core Features to Design 1. **College Onboarding:** Self-serve structure creation (Departments → Classes → Sections). 2. **Bulk Enrollment:** CSV-based student onboarding with auto-generated credentials. 3. **Adaptive Level System:** Checkpoint logic requiring balanced progress across Verbal, Logical, Quantitative, and Spatial domains. 4. **Mentor Portal:** Focused on live proctoring (risk flags, time per question, domain analytics). ## Technical Requirements * **Tech Stack:** Next.js, Tailwind CSS, shadcn/ui, Supabase, Google AI Studio (Gemini). * **Course Durations:** Auto-adjusts (MBA=4, BCA/BBA=6, Engineering=8 semesters). * **Proctoring:** Real-time tracking of tab switches, face detection, and audio anomalies.
