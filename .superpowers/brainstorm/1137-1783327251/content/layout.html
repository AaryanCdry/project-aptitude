A: Static sections — Pros

  • Zero clicks, setup items still one click away
  • Simpler to implement (~no state)
  • Nothing ever "hidden"

A: Static sections — Cons

  • Sidebar is still the same total height
  • Less visual "decluttering" payoff

B: Collapsible — Pros

  • Daily-use sidebar visually shrinks a lot
  • Reinforces "you rarely need this" signal

B: Collapsible — Cons

  • One extra click when setup IS needed
  • Needs open/closed state (localStorage) per admin
A

Static labeled sections

Both groups always fully visible, just visually separated by a label and spacing/divider.

B

Collapsible, Setup collapsed by default (recommended)

Daily Operations always expanded; Setup & Configuration starts collapsed and remembers state per admin.
